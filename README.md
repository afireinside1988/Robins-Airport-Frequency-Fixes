# Robin's Airport Frequency Fixes

Robin's Airport Frequency Fixes updates outdated or incomplete ATC frequencies for third-party airports in Microsoft Flight Simulator 2024.

The package is designed for users of modern ATC solutions such as BeyondATC and SayIntentions.AI, which rely on accurate airport communication frequencies.

## Features

- Updated published ATC frequencies
- Missing frequencies added
- Lightweight airport overrides
- No changes to airport infrastructure

## Data Sources

- all frequencies are verified using Navigraph (current AIRAC) for best compatibility with Flight Simulator

## Installation

Extract

zzzz-robins-airport-freq-fixes

into your MSFS 2024 Community folder.

## Reporting Issues

Found an airport with outdated or incorrect ATC frequencies?

Please open a GitHub Issue and include the following information:

- **Airport ICAO:** (e.g. EDDM)
- **Airport Name:** (optional)
- **Scenery Developer:** (e.g. Captain7, iniBuilds, Aerosoft, MK Studios)
- **Simulator Version:** (MSFS 2024)
- **Current Frequency/Frequencies:** (as shown in the simulator)
- **Correct Frequency/Frequencies:** (according to the latest published AIP or Navigraph Charts)
- **Additional Information:** (optional screenshots, comments, etc.)

Providing as much information as possible helps verify the issue and speeds up the implementation of future updates.

## Disclaimer

This project does not include or redistribute any Navigraph data.

Airport frequencies are independently verified using publicly available
official AIPs and/or current Navigraph charts. Only the resulting airport
frequency corrections are included in this package.
